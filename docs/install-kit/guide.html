장흥우체국 시범운영

안심ON 앱 설치 안내

위험 신고·귀국보고·관제실 알림을 휴대폰 앱처럼 쓰는 방법입니다.
앱스토어 없이 무료로 설치하며, 업데이트는 자동으로 됩니다.

카메라로 찍으세요
1

QR 코드를 찍고 링크를 누릅니다

휴대폰 카메라로 오른쪽 위 QR 코드를 비추면 링크가 뜹니다. 누르면 안심ON 로그인 화면이 열립니다.

2

아이디·비밀번호로 로그인합니다

아이디와 비밀번호는 안전보건담당자에게 받은 것을 입력하세요. 다른 사람과 같이 쓰지 마세요.
내 아이디:  (비밀번호는 종이에 적지 마세요)

3

홈 화면에 설치합니다

휴대폰 종류에 맞는 쪽을 따라 하세요.

안드로이드 갤럭시 등

  1. 로그인하면 화면 위에 "안심ON을 앱으로 설치하세요" 안내가 나옵니다. 앱 설치를 누르고 한 번 더 설치를 누릅니다.
  2. 버튼이 안 보이면 크롬 오른쪽 위 점 3개 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가를 누릅니다.
  3. 삼성 인터넷으로 열렸다면: 아래쪽 메뉴 ≡ → 현재 페이지 추가 → 홈 화면

아이폰

  1. 꼭 Safari로 엽니다. (카메라에서 뜬 링크를 누르면 Safari로 열립니다.)
  2. 아래쪽 공유 □↑ 버튼을 누릅니다.
    공유 버튼이 안 보이면 주소창 옆 점 3개 ··· → 공유
  3. 목록을 아래로 내려 홈 화면에 추가 → 오른쪽 위 추가를 누릅니다.
4

홈 화면의 안심ON 아이콘으로 실행하고, 알림을 켭니다

이제부터는 인터넷 창이 아니라 홈 화면의 안심ON 아이콘으로 여세요. 앱 안의 관제실 알림 켜기를 누르고 허용을 누르면 위험 알림·공지를 받을 수 있습니다.
아이폰은 홈 화면에 추가한 뒤에만 알림을 켤 수 있습니다(iOS 16.4 이상).

⚠ 다쳤거나 바로 위험한 상황이면 앱 전송을 기다리지 말고 즉시 전화하세요(소통실·119).

• 앱 알림은 휴대폰 상태(전원·데이터·절전 모드)에 따라 늦거나 오지 않을 수 있습니다.

• 시범운영 기간에는 시스템 점검 때 기록이 초기화될 수 있습니다.
