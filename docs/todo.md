## 1. 근거 검색 시뮬레이션 완성 (진행 중)

목적: ① 의미 검색을 포함한 근거 검색 정확도 높이기(담당자 말 ↔ 법령 말 괴리 해소) ② 보완할 자료를 찾아 Supabase에 추가.

### 1-0. 사용자가 할 일 (한 번만)

이 클라우드 환경에서 OpenAI·Supabase·운영 주소가 모두 막혀 있어(프록시 403) 실제 AI 채점을 돌릴 수 없다. 아래를 설정하면 이후는 에이전트가 직접 돌린다. 설정 후에는 **새 세션**에서 반영된다.

> 2026-10-31 확인: OpenAI·Supabase 연결 정상(Network secrets로 프록시가 키를 붙임, 코드는 `OPENAI_API_KEY=proxy`로 실행). KOSHA SQL 2건 적재 확인(문서 160건, 조문 6,462건 전부 의미 색인 완료). 운영 주소만 아직 차단(403).

- [x] **환경 설정 열기**: 세션 제목줄의 클라우드 환경 메뉴 → Edit
- [x] **비밀값(Network secrets, 없으면 환경변수) 추가**. 대화창에는 붙여넣지 않는다.
  - `OPENAI_API_KEY`: Railway에 넣은 것과 같은 OpenAI 키
  - `SAFETY_SUPABASE_URL`: Supabase 프로젝트 주소(`https://<프로젝트>.supabase.co`)
  - `SAFETY_SUPABASE_SERVICE_KEY`: Supabase service_role 키(Railway와 같은 값)
  - (선택) `SUPABASE_DB_URL`: Supabase → Connect → 연결 문자열. SQL 적재를 에이전트가 직접 하려면 필요
- [!] **Network access → Allowed domains 추가** (`ansimon-test-production.up.railway.app`만 아직 막힘) (Allow package managers는 체크 유지)
  - `api.openai.com`
  - `<프로젝트>.supabase.co`
  - `ansimon-test-production.up.railway.app` (운영 반영 확인용)
  - (선택) Supabase 연결 문자열의 호스트(예: `aws-0-ap-northeast-2.pooler.supabase.com`)
- [x] 아직 실행하지 않았다면 `local-import/kosha/kosha-guides-추가.sql`, `kosha-guides-그림옮김.sql`을 Supabase SQL Editor에서 실행. `SUPABASE_DB_URL`을 설정하면 에이전트가 대신 실행한다.

### 1-1. 에이전트가 할 일

- [ ] 골라내기(재순위) 단계 구현: 단어 + 의미 후보를 AI가 읽고 해당 조문만 이유와 함께 고름
- [ ] 실제 초안까지 만드는 채점 모드: 맞는 인용 / 엉뚱한 인용 / 골라내기가 버린 정답 수
- [ ] 세 방식 비교(기준점 단어만 · 참고 단어+의미 · 목표 단어+의미+골라내기), 업무 구역별 결과
- [ ] 시험 사례를 담당자 말투로 다시 작성하고, 기대 근거는 저장소와 무관하게 정함
- [ ] 놓친 사례를 "자료 없음"(추가할 자료)과 "있는데 못 찾음"(표현 차이)으로 나눠 보고
- [ ] 결과 재검토(다른 사례 세트로 교차 확인) 후 운영 적용 여부 결정
- [ ] 부족 자료 보완: KOSHA 창고(A-G-9)·지게차(B-M-11)·급식실(A-G-6)·고정식 사다리(B-M-1) 그림 PDF 옮겨 적기, LPG 사용시설 별표, 리튬 배터리 충전 안전자료

## 2. 장흥우체국 전 직원 계정 (대기)

목표: 장흥우체국 전체 인원이 개인 아이디·비밀번호로 앱을 쓰고, 위험성평가에서 관내 우체국별로 누가 보고했는지 집계한다.

- [ ] 현재 계정 구조 정리. 지금은 `server.js`에 고정 계정(jip, jip2, jip4, jip5, jip11~16)과 환경변수 비밀번호(`PW_*`)로 되어 있음
- [ ] 조직 구조 반영: 장흥우체국(총괄국) → 관내 우체국 → 직원. 사용자에게 관내국 목록과 직원 명단(이름·소속·역할) 양식 받기
- [ ] 계정 저장 방식 전환: 환경변수 고정 계정 → 명부 기반 계정(비밀번호는 해시로만 저장, 첫 로그인 시 비밀번호 변경)
- [ ] 관리자 화면: 직원 추가·퇴직 처리·비밀번호 초기화·소속 변경
- [ ] 신고·위험성평가에 보고자 소속(관내국) 기록, 관내국별·보고자별 집계와 엑셀 출력
- [ ] 보안: 로그인 시도 제한 복구(현재 데모용으로 꺼 둠), 세션 만료, 권한별 화면 접근

## 3. 안전보건관리담당자 홈페이지: 1년 산업안전 업무 통합 (대기)

목표: 우체국이 1년 동안 하는 산업안전 일정과 업무를 담당자 홈페이지 하나에서 계획·알림·기록·증빙한다.

- [ ] 연간 업무 목록 확정(사용자 확인 필요). 후보:
  - 위험성평가(정기·수시)와 개선조치 이행
  - MSDS(물질안전보건자료) 관리
  - 근골격계부담작업 유해요인조사
  - 직무스트레스 평가
  - 산업안전보건위원회·안전보건 회의 개최
  - 안전보건교육
  - 건강검진
  - 소방훈련·자체점검
  - 보호구 지급
  - 작업환경측정 해당 여부 검토
- [ ] 업무별 법정 주기·근거 조문 정리(Supabase 근거 활용)
- [ ] 연간 달력: 예정일·담당자·완료 여부·증빙 첨부, 다가오는 일정 알림
- [ ] 기존 위험성평가·이행결과서 화면과 연결
- [ ] 연말 실적 집계·출력
